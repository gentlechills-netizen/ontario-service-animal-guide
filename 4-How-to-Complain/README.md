# 4. How to Complain

If your rights are violated, documentation and a formal response are your strongest tools. This section guides you through the process of escalation.

### Escalation Path:

1. **Immediate Follow-up:** Use the email template for quick contact with store management.
2. **Formal Complaint:** Use the structured letter for a more serious legal notice.
3. **Real-Life Case:** Read how a recent access denial at a Kitchener community centre was successfully challenged.

_Persistence is key to removing barriers for everyone._
